# Belta Dairies Website

A responsive dairy-shop website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure, product cards, WhatsApp links, updates area, privacy policy and administrator demo.
- `style.css` — dairy-inspired design and responsive layout.
- `script.js` — mobile navigation and demo administrator tools.

## Open it on your computer
1. Download and extract `belta_dairies_website.zip`.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. To test the admin demo, scroll to **Administrator corner** and enter `belta123`.

## Important limitations before publishing
This is a front-end starter/demo. The administrator password is visible in `script.js`, and posts/media are stored in that browser's local storage. Therefore:
- It is **not secure enough for a real public administrator account**.
- Posts and videos added on one browser/device are **not automatically visible to other visitors**.
- Clearing browser data may delete saved posts.
- Large videos may fill browser storage.

To make administrator uploads and updates genuinely public, the next version needs a backend with secure administrator authentication and shared database/media storage (for example, a free-tier backend, subject to its current limits). Do not put private passwords or secrets in the website JavaScript.

- Review the privacy policy so it reflects the shop's actual practices.
